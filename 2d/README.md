# Astrocore 2D — Relay Two

Нативный 2D-клиент и сервер используют `astrocore-grid2d` из соседнего
чекаута `Astrocore-Engine`. Сборка использует корневой workspace и
`Cargo.lock` Astrocore Build.

Запустите локальный сервер и клиент из корня `Astrocore-Build`:

```bash
cargo play
```

Для одиночного запуска команда выбирает свободный локальный UDP-порт и
создаёт ключ сеанса. Для игры с несколькими клиентами задайте один общий
ключ из 64 шестнадцатеричных символов в `ASTRO_2D_KEY` и одинаковый адрес в
`ASTRO_2D_ADDR` во всех терминалах. Запустите отдельный сервер командой
`cargo serve2d`, затем откройте один или несколько клиентов командой
`cargo client2d`. При отдельных запусках адрес по умолчанию —
`127.0.0.1:7782`. Для открытия окна клиенту нужен дисплей.

В Bash можно сгенерировать новый ключ командой
`export ASTRO_2D_KEY="$(openssl rand -hex 32)"`.

В лобби выберите роль клавишей с её номером и подтвердите готовность клавишей
Enter. Раунд начинается, когда все подключённые готовы. Он заканчивается
после выполнения общей задачи, по таймеру или при потере всего экипажа.
После подведения итогов сервер восстанавливает карту и возвращает экипаж
в лобби.

На Relay Two оператор получает газоанализатор, инженер — строительный
набор и анализатор, медик — два перевязочных пакета. Снаряжение выдаётся
на старте раунда согласно `loadouts` в карте.

### Восстановление отсека

1. Включите резервный генератор в левом отсеке на клетке (4, 3), чтобы подать питание на шлюзы и вентиляцию.
2. Откройте шлюзы. Пройдите в правый отсек и закройте за собой шлюз, чтобы изолировать левый отсек.
3. Заделайте пробоину на восточной стене (20, 7) инженерным набором и включите подачу воздуха из резерва (16, 5). Резерв ограничен.
4. Следите за прогрессом вверху экрана. Экипаж побеждает, когда при герметичном корпусе и работающей вентиляции давление в контрольной точке держится от 82 кПа три секунды, а кислорода достаточно для дыхания.

| Клавиша | Действие |
| --- | --- |
| WASD или стрелки | Двигаться |
| E | Подобрать ближайший предмет или переключить шлюз либо генератор |
| X | Сменить активную руку |
| Q | Положить предмет из активной руки на пол |
| F | Использовать предмет в активной руке. Перевязочный пакет лечит себя, газоанализатор показывает давление, долю кислорода и температуру |
| G | Применить перевязочный пакет к раненому напарнику в соседней клетке под курсором |
| Щелчок по подписи руки | Выбрать пустую руку, переложить предмет в пустую активную руку или использовать предмет в активной руке |
| B | Поставить стену под курсором с инженерным набором в активной руке |
| N | Уложить пол в пустой клетке под курсором с инженерным набором |
| V | Разобрать стену или пол под курсором с инженерным набором |

Генератор питает оба шлюза кабельной сетью. Закрытый шлюз герметичен и
остаётся закрытым без питания. Открытый шлюз нельзя закрыть, пока проём
занят. Правый отсек сообщается с вакуумом через пробоину корпуса. Клиент
показывает давление и здоровье, а сервер рассчитывает потерю здоровья при
недостатке кислорода. При отключении игрока его предметы остаются на полу.

Инженерный набор лежит в левом отсеке. Строить и разбирать можно в соседней
клетке. Строительство расходует запас набора, разборка возвращает материал.
Сервер проверяет занятость клеток и защищает кабели, точки появления и
устройства. Разборка стены корпуса открывает отсек вакууму. Новая стена
закрывает пробоину. Укладка пола сама по себе воздух не добавляет.

Встроенная станция и прототипы находятся в `content/station.ron` и
`content/prototypes.ron`. Чтобы загрузить другой комплект, задайте серверу
`ASTRO_2D_CONTENT` с путём к каталогу, содержащему оба файла. Строки карты
идут сверху вниз. `.` обозначает пол, `#` стену, `~` космос. В координатах
размещений ось Y растёт вверх от нижней строки.

## Редактор карт

Откройте рабочую копию контента из корня `Astrocore-Build`.

```bash
station_dir="$(mktemp -d)"
cp 2d/content/*.ron "$station_dir/"
cargo editor2d "$station_dir"
```

Клавиши 1–3 выбирают пол, стену и космос, 4 — точку появления, 5 — кабель,
6 — объект. Tab перебирает прототипы. Левая кнопка мыши рисует выбранной
кистью, правая стирает. Z отменяет действие, Y повторяет его, F2 сохраняет.
Прототипы берутся из `prototypes.ron`. Если каталогу ещё не задан
`station.ron`, редактор открывает пустую сетку с точкой появления.

Редактор перед записью проверяет карту тем же загрузчиком, что сервер.
После сохранения запустите сервер с `ASTRO_2D_CONTENT="$station_dir"`,
чтобы сыграть на сохранённой карте.
