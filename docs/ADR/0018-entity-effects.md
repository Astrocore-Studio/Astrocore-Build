# ADR-0018. Эффекты и условия: реестр видов по тегу `!type:`

Дата: 2026-11-28. Статус: **принято** (исполнитель по плану фазы 7, задача 7.2).

## Контекст

В SS14 @ 2f4a2aad реакции, метаболизм реагентов, реакции тел на реагенты и многое другое
описывают действия списком эффектов (`EntityEffect`) с условиями (`EntityCondition`):

```yaml
effects:
- !type:HealthChange
  conditions:
  - !type:ReagentCondition
    reagent: Dylovene
    min: 1
  damage:
    types:
      Poison: -2
```

Общие поля эффекта — `conditions`, `minScale`, `scaling`, `probability`; условия
переворачиваются полем `inverted`. В SS14 эффект поднимается событием
`EntityEffectEvent<T>` на цели, и обрабатывает его система того компонента, который у цели
есть (урон — `Damageable`, появление сущности — `Transform`, температура раствора —
`Solution`). В данных SS14 больше сотни видов эффектов и условий; до 7.2 у нас был только
частный разбор эффектов дыхания (ADR-0009).

## Решение

1. **Реестр видов** (ресурс `World`): имя тега → функция разбора. Вид эффекта — объект с
   методом «применить к цели с масштабом», вид условия — «выполнено ли для цели». Модули
   регистрируют свои виды там же, где их системы (урон — в модуле урона, растворы — в
   модуле растворов), как в SS14 эффекты обрабатывают системы компонентов.
2. **Общие поля разбираются один раз** для любого вида: условия, `minScale`, `scaling`,
   `probability`, `inverted`. Применение — как `TryApplyEffect` SS14: порог масштаба,
   вероятность, условия, ограничение масштаба единицей без `scaling`.
3. **Неизвестный вид не применяется** и записывается в учёт (`check_content` показывает,
   каких видов ещё нет), как неизвестные поля компонентов.
4. **Вид сам проверяет нужные компоненты цели** (нет `Damageable` — урон не меняется), что
   повторяет выбор обработчика по компоненту в SS14.
5. Эффекты дыхания (ADR-0009) переходят на этот реестр вместе с метаболизмом (7.2в).

## Последствия

- Новые эффекты добавляются по одному, рядом со своими системами; данные SS14 не
  переписываются.
- Порядок и вероятности — как в SS14; вероятность берётся из общего генератора игры.
