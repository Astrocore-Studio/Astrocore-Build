# План работ Astrocore Build

План разбит на маленькие задачи: каждую можно сделать за вечер и закоммитить отдельно.
Сложность: **[RON]** — правка данных без Rust, **[Rust-]** — небольшая правка кода по образцу,
**[Rust+]** — новая логика, нужен разбор кода. Решения — в [ADR](ADR/), механики — в
[SYSTEMS.md](SYSTEMS.md). Сделанное отмечайте `[x]`.

Масштаб мира: **1 тайл = 1 м**, куб стены 1 × 1 × 1 м, этаж — два тайла стены (пол 0,2 м +
2 м стены + потолок 0,1 м = 2,3 м), персонаж ростом 1 тайл.

## Как работать

1. Запуск игры локально: `scripts/run_all.sh` (Windows — `run_all.bat`). Сервер даёт всем
   админ-ранг, консоль — клавиша `` ` ``, окно маппинга — F5. Карта: `ASTRO_MAP=<файл.ron>`.
2. Перед коммитом (всё должно быть без ошибок и предупреждений):
   ```bash
   cargo fmt
   ```
   ```bash
   cargo clippy --workspace --all-targets
   ```
   ```bash
   cargo test --workspace --no-fail-fast
   ```
3. Тест на механику — в `crates/gameplay/src/tests.rs` по образцу соседних (`harness_with`,
   команда клиента → тики → проверка). Задача без теста не считается сделанной.
4. Правка движка (`Astrocore-Engine`): после пуша в Build выполнить
   `cargo update -p <крейт движка>`, иначе Build соберётся со старой версией.
5. Не трогать контент NightCity (`_NC`).

## Этап 4. Перенос механик в системы

Каждая механика с отдельным файлом `impl State` становится `GameSystem`: забрать своё
состояние из `State`, команды — в `commands()`, тик — в `tick()`. Пошагово — [SYSTEMS.md](SYSTEMS.md),
раздел «Как добавить систему». Одна механика — один коммит, тесты зелёные на каждом шаге.
Порядок — от маленьких к большим (строк в файле):

- [ ] **4.4 [Rust-]** `conveyor.rs` (94) — конвейеры.
- [ ] **4.5 [Rust-]** `defib.rs` (123) — дефибриллятор.
- [ ] **4.6 [Rust-]** `round_end.rs` (129) — конец раунда.
- [ ] **4.7 [Rust-]** `mopping.rs` (168) — швабра.

- [ ] **4.10 [Rust+]** Большие куски `module.rs`: руки и инвентарь, бой, химия, атмосфера,
