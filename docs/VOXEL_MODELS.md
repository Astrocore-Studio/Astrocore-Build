# Воксельные модели: памятка художнику

Модели рисуем в [MagicaVoxel](https://ephtracy.github.io) (бесплатный, Windows и macOS). На Linux
подойдёт [Goxel](https://goxel.xyz) с экспортом в `.vox`. Своего редактора у Astrocore нет и не
планируется ([ADR-0002](ADR/0002-voxel-graphics.md)).

## Масштаб и оси

- **32 вокселя = 1 метр = 1 тайл.** Один воксель — один пиксель спрайта SS14.
- Ориентиры: персонаж — около 32 вокселей в высоту, куб стены — 32 × 32 × 32, стол — около 20
  в высоту, лом — около 4 × 4 × 28 (лежит на полу).
- В MagicaVoxel ось **Z — вверх**. Игра переводит оси сама: модель стоит основанием на полу,
  точка опоры — центр основания.
- **Перед модели** — сторона с меньшим **Y** в MagicaVoxel (в игре она смотрит на зрителя, как
  лицевая сторона спрайта). Если модель в игре стоит задом наперёд — разверните её на 180°
  вокруг Z.
- Одна модель — один файл. Из сцены MagicaVoxel с несколькими объектами берётся только первый.
- Размер — до 256 вокселей по каждой стороне. Палитра — до 255 цветов.

## Куда класть

Модель привязана к картинке спрайта, а не к прототипу (одну картинку делят многие прототипы).
Путь повторяет путь текстуры в `assets/ss14/Textures`:

| Спрайт | Модель |
| --- | --- |
| `Textures/Objects/Tools/crowbar.rsi/icon.png`, вещь лежит | `Models/Objects/Tools/crowbar.rsi/icon.flat.vox` |
| `Textures/Structures/Furniture/chairs.rsi/chair.png`, вещь стоит | `Models/Structures/Furniture/chairs.rsi/chair.vox` |

Лежащие вещи (предметы на полу) — с `.flat` перед расширением, стоящие (мебель, шкафы, автоматы) —
без. Если не уверены, посмотрите, какой файл `.avox` уже лежит рядом: сгенерированная модель
названа так же, только с расширением `.avox`.

Ручная `.vox` важнее сгенерированной `.avox`: её подхватит манифест рендера. Сгенерированную
удалять не нужно.

## Как увидеть в игре

1. Положите `.vox` по пути выше.
2. Пересоберите манифест рендера:
```bash
cargo run -p server -- --write-manifest assets/ss14/render-manifest.json
```
3. Запустите игру (`scripts/run_all.sh`), создайте предмет консолью (`spawn Crowbar`) или
   окном маппинга (F5) и посмотрите.

## Лицензия

Модель по мотивам спрайта SS14 — производная работа: она наследует лицензию набора RSI (поле
`license` в `meta.json` рядом с картинкой) и указывает авторов исходника. Полностью свою модель
опишите в коммите (автор и лицензия). Подробности — [assets/ss14/LICENSE-ASSETS.md](../assets/ss14/LICENSE-ASSETS.md).
