# Astrocore — игра на ядре сущностей

Сервер и клиент на ядре сущностей движка (ADR-0015 в Astrocore Engine). Прототипы, карты и
картинки читаются прямо из каталога `Resources` Space Station 14.

Сейчас работает: загрузка станции (по умолчанию Saltern), вход игроков по сети, ходьба со
столкновениями, отрисовка тайлов и спрайтов, сглаживание стен, окон и столов (`IconSmooth`).
Игрок пока получает тело корги: внешность гуманоидов — задача 3.10 плана. Двери, предметы,
свет, звук и окна интерфейса переносятся по [плану](../docs/ROADMAP.md).

## Запуск

Положите рядом Engine и референс SS14:

```bash
scripts/fetch_engine.sh
```

```bash
scripts/fetch_reference.sh
```

Игра в одиночку (сервер работает в процессе клиента):

```bash
cargo station
```

Выделенный сервер и клиент:

```bash
cargo serve
```

```bash
cargo client -- --connect 127.0.0.1:7783 --name Urist
```

Управление: WASD или стрелки, Shift — шаг.

## Настройка

| Что | Как |
|---|---|
| Каталог `Resources` SS14 | переменная `ASTRO_SS14_RESOURCES`; по умолчанию `../reference/space-station-14/Resources` |
| Свой контент поверх SS14 | каталог `Resources` в корне Build: его файлы важнее файлов SS14 |
| Адрес сервера | `ASTRO_ADDR`, по умолчанию `127.0.0.1:7783` |
| Ключ соединений | `ASTRO_KEY`, 64 шестнадцатеричных символа; одинаковый у сервера и клиентов |
| Карта раунда | `game.map` в `server_config.toml`, например `"Maps/bagel.yml"` |
| Тело игрока | `game.player_prototype` в `server_config.toml` |

Без `ASTRO_KEY` используется общеизвестный ключ: он годится только для игры на своём компьютере.
